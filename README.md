# ZalogHub

Простой список задач (todo list).

## Функциональность

- Добавление задачи через поле ввода и кнопку (Enter тоже добавляет)
- Переключение задачи: выполнена / не выполнена
- Удаление задачи
- Фильтрация: Все, Активные, Выполненные
- Сохранение задач в localStorage — после перезагрузки страницы они остаются

## Стек

- Vite
- React
- TypeScript
- обычный CSS

## Запуск

```
npm install
npm run dev
```

Сборка:

```
npm run build
npm run preview
```

## Затраченное время

Примерно 1 час.
